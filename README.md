# Physik 9/10 – Elektrostatik

Lernseite zur Reihe **Elektrostatik** (Physik 9/10, Bildungsplan NaWi Oberschule Bremen 08/2026).
Übungen, Trainer, Glossar, Formelsammlung, Checkliste und Simulationen für Schülerinnen und Schüler.

- Adresse: https://mr-co-osh.github.io/physik-elektrostatik/
- Keine Anmeldung, kein Tracking, keine externen Dienste. Alle Schriften liegen im Repo (SIL Open Font License, siehe `assets/fonts/LIZENZEN.txt` und `sim/fonts-*/LIZENZEN.txt`).
- Der Lernstand wird nur im Browser des jeweiligen Geräts gespeichert.
- Datenschutzhinweis: `datenschutz.html` – vor dem Veröffentlichen die gelb markierten Platzhalter (Verantwortliche, Kontakt, Rechtsgrundlage, Datum) ausfüllen.
- Aufbau nach dem Webseiten-Standard Physik 9/10; Vorbild ist die Lernseite Energie (`physik-energie`). Regeln: `STANDARDS.md`.
